# Diagnostic Platform Builder Skill

Specialized skill for engineering high-converting AI diagnostic tests, sales funnels, and interactive survey apps using Next.js, React, and Tailwind CSS.

## 1. Core Architecture
- **Framework**: Next.js (App Router / Pages Router) + TypeScript
- **Styling**: Tailwind CSS + Lucide Icons + Pretendard Font
- **Deployment Target**: Vercel (`my-diagnostic-app.vercel.app`)

## 2. Lead Funnel Guidelines
1. **Interactive Assessment**:
   - Dynamic step-by-step questionnaire with instant progress indicators.
   - Tailored score computation and personalized AI diagnosis reports.
2. **Sales Funnel CTA Integration**:
   - Clear conversion buttons linking to Bootcamp registration, KakaoTalk consultation, and phone consultations.
   - Responsive design with smooth animations and high-contrast glassmorphism cards.
