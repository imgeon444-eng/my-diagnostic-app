# Supabase & Database Architect Skill

Specialized skill for creating, migrating, and querying relational databases (PostgreSQL/Supabase) seamlessly through AI conversation.

## 1. Database Modeling Checklist
- **CRM & Lead Tables**: Design robust schemas for leads, survey answers, diagnostic scores, and user profiles.
- **Foreign Keys & Indices**: Ensure lightning-fast query lookups with proper index definitions.
- **Row Level Security (RLS)**: Enforce strict data isolation policies so users only access their own records.

## 2. Autonomous Migration Process
- Generate idempotent SQL scripts (`*.sql`).
- Apply migrations and verify schema integrity with dry-run queries.
- Generate TypeScript database types (`types/database.types.ts`) for 100% type-safe front-end integration.
